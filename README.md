# 🎓 ToU Bot (Торайгыров Университет)

> Telegram-бот для студентов Торайгыров Университета (ToU, г. Павлодар).  
> Предоставляет студентам быстрый доступ к расписанию занятий (текстом и PNG-карточками), виджету текущей пары, академическому статусу (GPA), журналу успеваемости и ключевым датам учебного года.

---

## ✨ Основные возможности бота

* 🔎 **Виджет «Текущая пара»**: в один клик показывает, какая пара идёт прямо сейчас, сколько минут осталось, какая аудитория, а во время перемены — подсказывает, куда идти на следующую пару.
* 📅 **Расписание занятий**: на Сегодня, Завтра и Всю неделю (альбомными карточками и текстом).
* 📌 **Академический статус**: отображение текущего GPA, курса, формы обучения, специальности и статуса студента.
* 📊 **Журнал успеваемости**: просмотр текущих баллов и оценок (в кратком и подробном виде).
* 📆 **Ключевые даты**: сроки семестра, рубежных контролей (РК-1, РК-2), экзаменационных сессий и каникул.
* 🔔 **Умные уведомления**: персональные напоминания за 5 минут до конца пары с указанием длительности перемены и следующей аудитории.
* 🧹 **Быстрая очистка чата (`/clear`)**: удаление истории сообщений бота в чате одной командой.
* 🛡️ **Многоуровневая безопасность**: пароли шифруются криптографией Fernet (AES-128), удаляются из чата при вводе и не передаются третьим лицам.

## 🏗️ Архитектура и структура проекта

Проект построен на **Python 3.10+** и асинхронном фреймворке **Aiogram 3.x** с разделением ответственности по слоям:

```text
tou_bot/
├── bot.py                        # Точка входа: инициализация Bot, Dispatcher, scheduler, регистрация команд
├── .env                          # Локальные переменные окружения и токены (в .gitignore)
├── .env.example                  # Шаблон конфигурации переменных окружения
├── requirements.txt              # Зависимости проекта
├── README.md                     # Документация проекта
├── SECURITY.txt                  # Подробное описание криптографии и архитектуры безопасности
├── CHANGELOG.md                  # История изменений версий
├── IDEAS.md                      # Копилка идей и бэклог фич
├── tou_bot.pyproj                # Проектный файл для Visual Studio
├── tou_bot.slnx                  # Решение для Visual Studio
│
├── data/                         # Локальное защищённое хранилище (в .gitignore)
│   ├── users_data.db             # База данных SQLite (учётные записи, кэш расписаний и журналов)
│   └── secret.key                # Ключ симметричного шифрования Fernet (AES-128)
│
└── src/                          # Исходный код приложения
    ├── __init__.py
    ├── config.py                 # Чтение .env, часовой пояс KZ (Asia/Almaty), расписание звонков ToU
    │
    ├── database/                 # Слой базы данных
    │   ├── __init__.py
    │   └── db.py                 # SQLite (aiosqlite), шифрование Fernet, кэширование расписания, GPA и оценок
    │
    ├── states/                   # FSM-состояния диалогов (Aiogram StatesGroup)
    │   ├── __init__.py
    │   ├── auth.py               # AuthForm (дисклеймер, логин, пароль, статус авторизации)
    │   └── admin.py              # AdminState (рассылка сообщений администратора)
    │
    ├── keyboards/                # Фабрики Inline-клавиатур
    │   ├── __init__.py
    │   └── inline.py             # Главное меню, виджет пары, расписание, успеваемость, настройки, админка
    │
    ├── services/                 # Бизнес-логика, парсинг и генерация медиа
    │   ├── __init__.py
    │   ├── tou_client.py         # HTTP-клиент портала ToU (httpx: авторизация, сессии, получение HTML)
    │   ├── parser.py             # Парсер расписания, ключевых дат, статуса и оценок (BeautifulSoup)
    │   ├── image_generator.py    # Рендеринг расписания в красивые PNG-карточки и альбомы (Pillow)
    │   ├── scheduler.py          # Асинхронный планировщик персональных уведомлений об окончании пар
    │   └── admin_alerts.py       # Мониторинг бота, отслеживание сбоев портала ToU и алерты админам
    │
    ├── handlers/                 # Aiogram-обработчики (Routers)
    │   ├── __init__.py           # Сборка всех роутеров в единый main_router
    │   ├── auth.py               # /start, дисклеймер, авторизация (ручная и быстрый вход)
    │   ├── schedule.py           # Просмотр расписания (Сегодня, Завтра, альбомная Неделя)
    │   ├── admin.py              # /admin, статистика пользователей, массовая рассылка
    │   └── common.py             # /clear, виджет пары, успеваемость, GPA, ключевые даты, настройки
    │
    └── utils/                    # Вспомогательные утилиты и константы
        ├── __init__.py
        ├── texts.py              # Системные тексты, дисклеймер и политика конфиденциальности
        ├── cleanup.py            # Очистка сообщений альбомов, журнала оценок и история чата (/clear)
        └── lesson_widget.py      # Логика виджета "Текущая пара" (сопоставление пар, таймеры, аудитории)
```

## 🚀 Быстрый старт

### 1. Клонирование и виртуальное окружение
```bash
git clone https://github.com/kaialish/tou_bot.git
cd tou_bot

python -m venv .venv
# Активация окружения (Windows PowerShell):
.venv\Scripts\Activate.ps1
# Или в Linux / macOS:
# source .venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте `.env.example` в `.env` и укажите данные:
```bash
copy .env.example .env
```
Заполните:
```env
BOT_TOKEN=123456789:ABCdef...
ADMIN_IDS=123456789,987654321
TZ=Asia/Almaty
```

### 4. Запуск бота
```bash
python bot.py
```

## 🤖 Основные команды бота

* `/start` — Запуск бота, авторизация или открытие Главного меню.
* `/clear` (или `/clean`) — Быстрая очистка чата от старых сообщений бота.
* `/admin` — Панель администратора (доступна только ID из `ADMIN_IDS`).

## 🛡️ Безопасность данных

- **Шифрование паролей**: Пароли студентов шифруются криптографическим алгоритмом **Fernet (AES-128-CBC + HMAC-SHA256)** перед записью в SQLite базу `data/users_data.db`.
- **Защита в чате**: Сообщение с паролем немедленно удаляется из истории переписки при вводе.
- **Изоляция секретов**: Файлы `data/secret.key`, `data/users_data.db` и `.env` строго изолированы в `.gitignore`.
- **Защищённый транспорт**: Все запросы к порталу ToU и Telegram API выполняются по протоколу HTTPS (TLS 1.2/1.3).
- **Подробный отчёт**: Детальное описание архитектуры безопасности доступно в файле [`SECURITY.txt`](SECURITY.txt).
