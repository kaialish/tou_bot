# 🎓 ToU Bot & Mini App (Торайгыров Университет)

> Многофункциональная экосистема для студентов Торайгыров Университета (ToU, г. Павлодар).  
> Объединяет полнофункционального Telegram-бота и интерактивное Telegram Mini App (TMA): расписание занятий (текстом, PNG-карточками и в интерактивном веб-интерфейсе), виджет текущей пары, академический статус (GPA), журнал успеваемости с цветовой индикацией баллов, умные уведомления и инструменты безопасности.

---

## ✨ Основные возможности экосистемы

### 📱 1. Telegram Mini App (TMA)
Современный адаптивный веб-интерфейс, запускаемый прямо внутри Telegram (в один клик из меню бота):
* 📅 **Интерактивное расписание**: удобное переключение дней недели, карточки пар с бейджами типов занятий (лекции, практики, лабы), аудиториями и преподавателями.
* ⏱️ **Live-виджет «Текущая пара»**: динамический таймер оставшегося времени пары в шапке приложения.
* 📊 **Журнал успеваемости с цветовой подсветкой**:
  * 🟢 **Зелёный (≥ 70)** — высокий балл;
  * 🟠 **Оранжевый (51–69)** — допустимый порог;
  * 🔴 **Красный (≤ 50)** — академический риск / задолженность;
  * ⚪ **Белый (0)** — отсутствие баллов.
  * Разделение на **1-ю и 2-ю половину семестра**, детальная сетка недель, баллы ТУ (текущая успеваемость), РК (рубежный контроль) и рейтинги.
* 📌 **Академический статус & Ключевые даты**: текущий GPA, проверки допуска к сессии, отсчёт дней до рубежек, сессий и каникул.
* 👤 **Telegram-аватарка студента**: безопасное отображение фото профиля Telegram вместо стандартной иконки (с серверным кэшированием).
* 🛡️ **Панель администратора**: защищённая вкладка (доступна только для ID из `ADMIN_IDS`) со статистикой пользователей, списком входов, тумблером техработ и пингом портала ToU.
* 🎮 **Демо-режим**: возможность протестировать возможности Mini App на реалистичных мок-данных без ввода логина и пароля.

---

### 🤖 2. Функции Telegram-бота
* 🔎 **Виджет «Текущая пара» в чате**: показывает текущее занятие, остаток времени, следующую аудиторию и длительность перемены.
* 📅 **Расписание в чате**: текстовые сообщения и генерация красивых альбомных PNG-карточек расписания на Сегодня, Завтра и Неделю.
* 🔔 **Умные персональные уведомления**: напоминание за 5 минут до конца пары с аудиторией следующего занятия.
  * 🧹 **Авто-очистка**: удаление предыдущего уведомления при отправке нового.
  * 📱 **Тумблер MOOK**: выборочное отключение напоминаний для дистанционных дисциплин.
* 🛡️ **Безопасность Zero-Storage / Fernet**:
  * **⚡ Обычный (Быстрый вход)** — безопасное двустороннее шифрование Fernet (AES-128-CBC) для обновления данных в один клик.
  * **🛡️ Максимальная безопасность** — пароль не сохраняется на диск и мгновенно стирается из памяти.
  * **🗑️ Право на забвение** — полное удаление аккаунта, подписок и кэша одной кнопкой.
* 🧹 **Очистка чата (`/clear`)**: удаление истории сообщений бота по команде.
* 🎮 **Команда `/demo`**: мгновенная ссылка на демонстрационный режим Mini App.

## 🏗️ Архитектура и структура проекта

Проект построен на **Python 3.10+**, фреймворке **Aiogram 3.x** и асинхронном HTTP-сервере **aiohttp** (для Mini App API). Архитектура строго разделена по слоям ответственности:

```text
tou_bot/
├── bot.py                        # Главная точка входа: параллельный запуск Aiogram-бота и Mini App HTTP-сервера
├── railway.json                  # Конфигурация деплоя на платформу Railway (Nixpacks)
├── requirements.txt              # Зависимости проекта
├── README.md                     # Документация проекта
├── SECURITY.txt                  # Подробное описание криптографии и архитектуры безопасности
├── CHANGELOG.md                  # История версий и изменений
├── IDEAS.md                      # Бэклог идеи и планы развития
│
├── docs/                         # Академическая и проектная документация (.docx)
├── tests/                        # Автоматизированные регрессионные и модульные тесты
│
├── webapp/                       # Клиентская часть Telegram Mini App (HTML5 / TailwindCSS / Vanilla JS)
│   ├── index.html                # Каркас приложения, навигация, вкладки, модалки
│   ├── app.js                    # Логика TMA, Telegram WebApp SDK, рендеринг расписания, оценок и админки
│   └── mock_data.js              # Тестовые данные студента для демо-режима
│
├── data/                         # Защищённое хранилище (в .gitignore, на Railway монтируется Volume)
│   ├── users_data.db             # База данных SQLite (учётные записи, подписки, кэш)
│   └── secret.key                # Ключ шифрования Fernet (резервный локальный источник)
│
└── src/                          # Исходный код бэкенда
    ├── config.py                 # Чтение .env, часовой пояс (Asia/Almaty), расписание звонков ToU
    ├── webapp_server.py          # Сервер API для Mini App (aiohttp): JSON-эндпоинты, аватарки, админка
    │
    ├── database/                 # Слой базы данных (SQLite / aiosqlite)
    │   ├── __init__.py           # Единый фасад для обратной совместимости
    │   ├── crypto.py             # Управление ключом SECRET_KEY (.env, Windows Registry, файл) и Fernet
    │   ├── schema.py             # DDL схемы таблиц и безопасные миграции колонок (init_db)
    │   └── repositories/         # Модульные репозитории данных
    │       ├── users.py          # Авторизация, пароли, статистика пользователей, удаление данных
    │       ├── subscriptions.py  # Уведомления об окончании пар, тумблер MOOK, формат расписания
    │       ├── cache.py          # Кэширование расписания, GPA и журнала оценок
    │       └── system.py         # Состояние техработ (maintenance mode)
    │
    ├── services/                 # Бизнес-логика, парсинг и генерация медиа
    │   ├── __init__.py           # Фасад сервисов
    │   ├── tou_client.py         # HTTP-клиент портала ToU (httpx: авторизация, сессии, сбор HTML)
    │   ├── image_generator.py    # Рендеринг расписания в альбомные PNG-карточки (Pillow)
    │   ├── scheduler.py          # Планировщик персональных напоминаний об окончании пар (APScheduler)
    │   ├── admin_alerts.py       # Мониторинг бота и алерты администраторам
    │   └── parsers/              # Декомпозированные парсеры HTML
    │       ├── schedule_parser.py # Парсер расписания занятий
    │       ├── grades_parser.py   # Парсер журнала успеваемости, баллов ТУ и РК
    │       ├── status_parser.py   # Парсер академического статуса (GPA, проверки)
    │       └── dates_parser.py    # Парсер и расчёт ключевых дат учебного года
    │
    ├── handlers/                 # Aiogram-обработчики событий Telegram
    │   ├── __init__.py           # Сборка роутеров в единый main_router
    │   ├── auth.py               # /start, /demo, авторизация, выбор режима безопасности
    │   ├── schedule.py           # Просмотр расписания в чате (Сегодня, Завтра, Неделя)
    │   ├── academic.py           # Карточка GPA, академический статус, ключевые даты
    │   ├── grades.py             # Просмотр журнала успеваемости в чате
    │   ├── settings.py           # Меню настроек, уведомления, тумблер MOOK, удаление аккаунта
    │   ├── admin.py              # Панель администратора в чате (/admin, рассылки)
    │   └── common.py             # Базовые хэндлеры: /clear, виджет пары, навигация
    │
    ├── states/                   # FSM-состояния (Aiogram StatesGroup)
    │   ├── auth.py               # Состояния авторизации и выбора режима
    │   └── admin.py              # Состояния массовой рассылки
    │
    ├── keyboards/                # Inline-клавиатуры для чата
    │   └── inline.py             # Главное меню, запуск Mini App, демо-кнопка, настройки
    │
    └── utils/                    # Вспомогательные утилиты
        ├── texts.py              # Тексты дисклеймера и политики конфиденциальности
        ├── cleanup.py            # Очистка сообщений и альбомов в чате
        ├── rate_limit.py         # Защита от спам-запросов (cooldown 60 секунд)
        └── lesson_widget.py      # Расчёт текущей пары, времени перерывов и аудиторий
```

## 🚀 Быстрый старт локально

### 1. Клонирование и виртуальное окружение
```bash
git clone https://github.com/kaialish/tou_bot.git
cd tou_bot

python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux / macOS:
# source .venv/bin/activate
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Переменные окружения (`.env`)
Создайте файл `.env` в корне проекта:
```env
# Токен бота от @BotFather
BOT_TOKEN=123456789:ABCdef...

# Telegram ID администраторов через запятую
ADMIN_IDS=123456789,987654321

# Часовой пояс (Казахстан UTC+5)
TZ=Asia/Almaty

# Постоянный ключ шифрования Fernet (сгенерируйте командой ниже)
SECRET_KEY=сгенерированный_ключ_fernet

# URL для Telegram Mini App (локально через Cloudflare Tunnel или production Railway URL)
WEBAPP_URL=https://toubot-production.up.railway.app

# Порт HTTP-сервера Mini App (по умолчанию 8080)
PORT=8080
```

> **Генерация ключа Fernet:**
> ```bash
> python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
> ```
> *(На Windows ключ можно также один раз сохранить в реестре `HKCU\Environment\SECRET_KEY`, и бот автоматически подхватит его без явного указания в файле).*

### 4. Запуск локально
```bash
python bot.py
```
*Бот запустится вместе с сервером Mini App на `http://localhost:8080`.*  
Для тестирования кнопки Mini App внутри Telegram воспользуйтесь официальным туннелем:
```bash
python download_cloudflared.py
.\cloudflared.exe tunnel --url http://localhost:8080
```
*(Скопируйте выданный `https://xxxx.trycloudflare.com` в переменную `WEBAPP_URL`).*


## 🤖 Команды бота

* `/start` — Авторизация, вход под сохранённым аккаунтом или открытие меню.
* `/demo` — Запуск интерактивной демо-версии Mini App без авторизации.
* `/clear` (или `/clean`) — Быстрая очистка чата от сообщений бота.
* `/admin` — Панель управления администратора (статистика, рассылка, статус портала).

## 🛡️ Безопасность и защита данных

- **Шифрование Fernet (AES-128-CBC)**: Пароли студентов надёжно зашифрованы криптографическим ключом, изолированным от репозитория.
- **Режим Zero-Storage**: Студент может выбрать режим максимальной приватности — пароль не сохраняется в базу вообще.
- **Rate Limiting**: Встроенное ограничение частых запросов (cooldown 60 секунд) предотвращает блокировку аккаунтов на портале ToU.
- **Право на забвение**: Кнопка «Удалить все мои данные» в настройках стирает все следы студента из базы.
- **Подробный отчёт**: Дополнительные детали криптографии описаны в [`SECURITY.txt`](SECURITY.txt).
