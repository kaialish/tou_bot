

bot.py — Главный файл бота. Отвечает за интерфейс Telegram, приём сообщений, Inline-кнопки и логику диалога с пользователем.

tou_client.py — Сессия и авторизация. Отправляет HTTP-запросы на портал tou.edu.kz, выполняет вход по логину/паролю и держит куки.

parser.py — Разбор страницы. Извлекает из HTML-кода дашборда список пар (время, предмет, аудитория, тип занятия).

image_generator.py — Отрисовка расписания. Принимает спарсенные данные и с помощью Pillow рисует PNG-картинку для отправки в чат.

config.py / config.py.example — Настройки и токены. Хранит BOT_TOKEN, URL-адреса портала и заголовки браузера (шаблон нужен для GitHub без слива токена).

requirements.txt — Список зависимостей. Содержит перечень библиотек (aiogram, httpx, beautifulsoup4, pillow) для быстрой установки командой pip install -r requirements.txt.

.gitignore — Защита репозитория. Указывает Git, какие файлы не нужно загружать на GitHub (config.py, кэш, служебные папки вроде .vs).
