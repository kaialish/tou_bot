# 🎓 ToU Bot (Торайгыров Университет)

> Telegram-бот для студентов Торайгыров Университета (ToU, г. Павлодар).  
> Позволяет быстро просматривать актуальное расписание занятий на Сегодня, Завтра и Всю неделю (альбомным видом) прямо из Telegram с генерацией наглядных графических карточек.

---

## 🏗️ Архитектура и структура проекта

Проект построен на **Python 3.10+** и фреймворке **Aiogram 3.x** с разделением ответственности по слоям (роутеры, состояния FSM, сервисы, клавиатуры, утилиты, хранилище данных):

```text
tou_bot/
├── bot.py                        # Точка входа: Bot, Dispatcher, регистрация роутеров, запуск polling
├── .env                          # Локальные переменные окружения и токен (в .gitignore)
├── .env.example                  # Шаблон конфигурации переменных окружения
├── requirements.txt              # Зависимости проекта
├── README.md                     # Документация проекта
├── CHANGELOG.md                  # История версий
├── IDEAS.md                      # Копилка идей и бэклог фич
├── tou_bot.pyproj                # Проектный файл для Visual Studio
├── tou_bot.slnx                  # Решение для Visual Studio
│
├── data/                         # Локальное защищённое хранилище (в .gitignore)
│   ├── users_data.db             # База данных SQLite (учётные записи)
│   └── secret.key                # Ключ симметричного шифрования Fernet
│
└── src/                          # Исходный код приложения
    ├── __init__.py
    ├── config.py                 # Чтение .env, BOT_TOKEN, ADMIN_IDS, URL портала ToU
    │
    ├── database/                 # Слой базы данных
    │   ├── __init__.py
    │   └── db.py                 # SQLite, шифрование Fernet, CRUD учётных записей и статистика
    │
    ├── states/                   # FSM-состояния диалогов (Aiogram StatesGroup)
    │   ├── __init__.py
    │   ├── auth.py               # AuthForm (дисклеймер, логин, пароль, авторизован)
    │   └── admin.py              # AdminState (рассылка сообщений)
    │
    ├── keyboards/                # Фабрики Inline-клавиатур
    │   ├── __init__.py
    │   └── inline.py             # Главное меню, дисклеймер, расписание, админ-панель
    │
    ├── services/                 # Бизнес-логика, парсинг и генерация медиа
    │   ├── __init__.py
    │   ├── tou_client.py         # HTTP-клиент портала ToU (httpx: авторизация, cookies, mod=rasp)
    │   ├── parser.py             # Парсер расписания BeautifulSoup (предметы, типы, ауд., препод.)
    │   └── image_generator.py    # Рендеринг расписания в PNG-карточки и альбомы (Pillow)
    │
    ├── handlers/                 # Aiogram-обработчики (Routers)
    │   ├── __init__.py           # Сборка всех роутеров в единый main_router
    │   ├── auth.py               # /start, дисклеймер, авторизация (ручная и быстрый вход)
    │   ├── schedule.py           # Просмотр расписания (Сегодня, Завтра, альбомная Неделя)
    │   ├── admin.py              # /admin, статистика пользователей, рассылка
    │   └── common.py             # Навигация «Назад в меню», заглушки нереализованных разделов
    │
    └── utils/                    # Вспомогательные утилиты и константы
        ├── __init__.py
        ├── texts.py              # Шаблоны системных текстов и дисклеймер
        └── cleanup.py            # Очистка предыдущих сообщений альбомов из чата
```

## 🚀 Быстрый старт

### 1. Клонирование и виртуальное окружение
```bash
git clone https://github.com/kaialish/tou_bot.git
cd tou_bot

python -m venv .venv
# Активация окружения (Windows PowerShell):
.venv\Scripts\Activate.ps1
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Скопируйте `.env.example` в `.env` и укажите данные:
```bash
copy .env.example .env
```
Заполните:
```env
BOT_TOKEN=123456789:ABCdef...
ADMIN_IDS=123456789,987654321
```

### 4. Запуск бота
```bash
python bot.py
```

## 🛡️ Безопасность данных

- Пароли студентов **не сохраняются в открытом виде**.
- Для каждого развёртывания в папке `data/` создаётся уникальный ключ `secret.key`.
- Пароли шифруются алгоритмом **AES (Fernet CBC + HMAC)** перед записью в SQLite `data/users_data.db`.
- Каталог `data/` и файл `.env` изолированы правилами `.gitignore`.
